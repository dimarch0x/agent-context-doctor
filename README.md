# Agent Context Doctor

Линтер файлов контекста ИИ-агентов: проверяет `AGENTS.md`, `CLAUDE.md` и `SKILL.md`
против реального репозитория и находит то, что делает агентов глупее.

## Зачем

По исследованию 2026 года, в 79 прогонах из 80 агент следовал устаревшему правилу из
`CLAUDE.md`, хотя код давно жил иначе; 73,8% таких файлов не обновляли ни разу.
Проблема не в модели, а в том, что правила никто не проверяет.

## Что проверяет

| Проверка | Что ловит | По умолчанию |
|---|---|---|
| `dead-path` | путь в правилах, которого нет на диске | error, если каталог существует |
| `dead-command` | `npm run X`, `make X`, `python3 scripts/x.py`, которых нет | warning |
| `version-drift` | версия в правилах ≠ версии в `pyproject.toml` / `package.json` | warning |
| `skill-frontmatter` | нет frontmatter, `name` ≠ каталог, битые ссылки на `scripts/` | error / warning |
| `duplicate-rule` | одно правило в нескольких файлах — разойдётся | info |

Серьёзность выводится из факта, а не из догадки: файл пропал из существующего каталога —
ошибка; каталог не существует, но предок есть — предупреждение; не существует ничего,
или путь явно создаётся по инструкции, или это кластер примеров структуры проекта —
заметка.

## Установка и запуск

```bash
python3 -m agctx scan .              # текущий каталог
python3 -m agctx scan ~/.dsh         # корпус скиллов и AGENTS.md
python3 -m agctx scan . --json       # машинный вывод
python3 -m agctx scan . --check dead-path --check skill-frontmatter
python3 -m agctx scan . --no-info
```

Коды возврата: `0` — чисто, `1` — только предупреждения, `2` — есть ошибки, `3` — путь не найден.
Удобно вешать в CI: ошибки валят сборку, предупреждения нет.

## Результаты на живом корпусе (ноябрь 2026)

| Корпус | Файлов | Ошибок | Предупреждений | Заметок | Время |
|---|---|---|---|---|---|
| `~/.dsh` (скиллы DSH) | 16 | 0 | 8 | 37 | ~0,15 с |
| `~/.hermes/hermes-agent` (монорепо) | 223 | 13 | 193 | 487 | ~0,4 с |
| `~/Projects` (рабочие проекты) | 41 | 4 | 8 | 80 | ~0,2 с |

До настройки правил серьёзности тот же Hermes давал 188 ошибок и 568 предупреждений —
почти всё это были API-роуты, примеры структуры проекта и пути чужих машин. Шум убирался
правилами, а не списком исключений.

Пример находки, которая пережила все фильтры:

```
ERR  [dead-path] Project_NoName/adaptive-cachy-beauty/.agents/skills/agent-repo-init/SKILL.md:23
     — путь не существует: /home/dmitry/AGENTS.md
```

## Тесты

```bash
python3 -m unittest discover -s tests -t . -v
```

33 теста: разбор frontmatter, эвристики путей, каждая проверка, кластеры примеров,
коды возврата и JSON.

## Ограничения MVP

- Проверяются только пути в инлайн-коде (обратные кавычки), не в прозе.
- `version-drift` срабатывает лишь там, где версия стоит в одной строке с именем проекта.
- Конфликты правил ищутся по совпадению текста, не по смыслу.
- Семантическое сравнение правил и проверка по внешним докам — в следующей версии.
